# V8 host v1: "use rust" inside a normal Convex action (D-104)

Runs a `"use rust"` crate on stock Convex (cloud or self-hosted, no backend or CLI changes). The guest is the
unchanged `wasm32-wasip1` artifact and guest ABI v1 (ABI.md). Two parts:

1. `convex-rust` npm package (main repo `packages/convex-rust/`):
   - `convex-rust/runtime`: the JS host. Default Convex runtime only (needs JSPI); never `"use node"`.
   - `convex-rust` bin: `convex-rust build [--watch] [--out <dir>] [--profile release|dev]` builds the crate in
     `convex/rust/` and writes the generated files below. `convex-rust init` scaffolds the crate.
2. Generated files (checked in or gitignored by the user's choice), default `--out convex/rust`:
   - `<out>/_wasm/<crate>.wasm` (wasm-opt'd when `wasm-opt` is on PATH).
   - `<out>/<module>.ts` per Rust module that has actions, one export per action, so function paths match
     the backend-hosted runtime: `rust/<module>:<name>` (`api.rust.<module>.<name>`).
   - `<out>/_wasm.d.ts`: `declare module "*.wasm" { const m: WebAssembly.Module; export default m; }`.
   - Every generated file starts with `// @generated by convex-rust. Do not edit.`

## Generated wrapper shape

```ts
// @generated by convex-rust. Do not edit.
import { action, internalAction } from "../_generated/server";
import { v } from "convex/values";
import { runRust } from "convex-rust/runtime";
import wasm from "./_wasm/<crate>.wasm";

export const cpu_001 = action({
  args: <validator from manifest `args`, or v.any() fields-less form: {} with no validation when absent>,
  returns: <validator from manifest `returns`, omitted when absent>,
  handler: (ctx, args) => runRust(ctx, wasm, "convex_run:<modulePath>:<name>", args),
});
```

Module path → file: the Rust `module_path!()` minus the crate name, `::` → `/`; crate root → `lib`
(same mapping as the backend-hosted runtime / MANIFEST.md). `internal` visibility → `internalAction`.

## `runRust(ctx, module, exportName, args): Promise<Value>`

- Instantiates `module` (a `WebAssembly.Module`, compiled once per isolate by the bundler stub) per call; one
  instance runs one call (ABI v1). Calls `_initialize` if exported.
- Args: `convexToJson(args)` → UTF-8 → `convex_alloc` → `convex_run:*` via `WebAssembly.promising`.
- Imports (module `convex`):
  - `task_submit(ptr,len)`: parse request; start the operation; return a task id (`-1` on malformed JSON).
    `syscall` names map to ctx: `1.0/actions/query|mutation|action` → `ctx.runQuery|runMutation|runAction(
    functionRef(args), jsonToConvex(args))` where `functionRef` is the `functionHandle` string, a `{[Symbol.for("toReferencePath")]: reference}`
    object, or `makeFunctionReference(name)`, in that order; `1.0/actions/schedule` → `ctx.scheduler.runAt(ts*?,...)`
    per the V8 syscall's semantics; `1.0/getUserIdentity` → `ctx.auth.getUserIdentity()`. `1.0/actions/vectorSearch` → `ctx.vectorSearch`;
    `1.0/storageGenerateUploadUrl` → `ctx.storage.generateUploadUrl()`. Others: forwarded to the global
    `Convex.asyncSyscall(name, json)`; error event `Unsupported syscall in the V8 host: <name>` if there is none. `fetch` → global `fetch`, body streamed as `chunk` events;
    `sleep` → `setTimeout`; `storageStore` → `ctx.storage.store(new Blob([bytes], {type}))`; `storageGet` →
    `ctx.storage.get(id)`.
  - `task_poll(block)`: `block = 0` returns the next queued event or `0`; `block = 1` is a
    `WebAssembly.Suspending` import that awaits the next event; `-1` when nothing is outstanding.
  - `sync_syscall`: `now` → `Date.now()`; `componentArgument` → `Convex.syscall("1.0/componentArgument", {name})`, reply `{value}` → `ok`, `{}` → `ok: null`.
  - `log(level, ptr, len)` → `console.debug|log|warn|error`.
- WASI `wasi_snapshot_preview1`: `environ_*` from `process.env`, `clock_time_get`, `random_get`
  (`crypto.getRandomValues`, 64 KiB chunks), `fd_write` fds 1/2 → `console.log`/`console.error` split on
  `\n`, `proc_exit` → throw. Everything else returns `ENOSYS` (52).
- Result envelope: `{"ok"}` → `jsonToConvex`; `{"error"}` → `throw new ConvexError(data)` when
  `kind = "convex"` and `data` present, else `throw new Error(message)`. Trap → `Error("Uncaught Error: <last
  panic line>")` when the panic convention line was logged, else the trap message.
- Fast paths (all semantically identical to the plain `convexToJson`/`jsonToConvex` route; anything unusual falls back to those
  functions so values and error messages are theirs): args are written with one `JSON.stringify` replacer
  (`$float`/`$integer`/`$bytes` via the built-in base64, keys emitted in sorted order exactly like `convexToJson`, field-name,
  `undefined` and unsupported-type validation preserved); results are decoded in place on the parsed envelope.
- Binary chunk events: when the guest exports `convex_binary_events` (ABI.md), stream data chunks are written into guest memory
  as `0x01 | u8 id_len | id | bytes` instead of JSON + base64; older guests keep JSON.
- Sleeps: all `sleep` tasks of a call share one `setTimeout` for the earliest deadline; a wake delivers every sleep that is due
  (ordered by deadline, then creation), so N timers cost one timer round trip per distinct wake, not N.
- `convex_free(ptr: i32, len: i32)` (optional guest export, wasm32 `convex_fn`): after the host has read the result envelope it
  calls it with the two halves of the packed result so the guest frees the buffer (the result is an exactly sized boxed
  slice). Guests without the export just keep the buffer until the instance is dropped (as before). Not freed when `len = 0`.
- Error and log text matches the backend-hosted runtime wherever the V8 action machinery allows (spec parity).

## HTTP actions: `runRustHttp(ctx, module, exportName, request): Promise<Response>`

For `#[http_action]` exports (manifest `kind: "http"`); the generated wrapper is
`export const h = httpAction((ctx, request) => runRustHttp(ctx, wasm, "convex_run:<mod>:<name>", request))`, routed with
`http.route({ path, method, handler: rust.<module>.<name> })`. Same instance handling, syscalls, WASI and error mapping as `runRust`.

- Args: `{method, url, headers: [[k,v]], bodyStreamId}`; `request.body` (a `ReadableStream`) is opened as a host stream
  (the `fetch` response-body machinery, chunk events, binary when supported), `null` for bodiless requests.
- Buffered answer: envelope `ok` = `{status, headers, body: base64|null}` is returned as a `Response` (no `convexToJson`
  decoding; statuses 204/205/304 carry no body).
- Streamed answer: `httpStart` creates the `Response` (its body is a `ReadableStream`, high-water mark 1 MiB) and `runRustHttp`
  returns it immediately; `httpWrite` tasks enqueue and complete once the client has room (backpressure); `httpEnd` or the guest
  returning closes the body; a guest error after `httpStart` errors the body. A client cancel makes the next `httpWrite` fail.
- Limits: request and response bodies at most 20 MiB (`httpWrite` fails beyond it); a buffered body also has to fit the 16 MiB result limit.
- Status must be 200..599 (`Error` otherwise). Not available in the wasmtime host.

## Versioning

`runRust` checks the guest exports `convex_alloc` and the requested `convex_run:*`; a missing export throws
`Could not find function <name> in module <module>` (same text as the backend-hosted runtime). Additive changes
only within v1.
