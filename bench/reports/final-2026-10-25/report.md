# Final benchmark summary (2026-10-25)

Full report: `report.html` (self-contained). Metric: end-to-end client time (D-105). Headline cells are medians of
per-case ratios; below 1 means the numerator is faster. Generated by `bench_report final` (see bench/README.md).

## Local: rust-native vs node (fork backend, 100 cases, macOS aarch64)

| metric | native/node | n | faster / slower |
|---|---|---|---|
| warm p50 | 0.426 | 100 | 94 / 2 |
| warm p95 | 0.408 | 100 | 92 / 3 |
| cold p50 (2 rounds) | 0.371 | 100 | 94 / 4 |
| conc 10 (inverse throughput) | 0.178 | 100 | 91 / 7 |
| conc 50 (inverse throughput) | 0.224 | 100 | 73 / 23 |

Phase-1 correctness: 100/100 equal. Gates: crypto, spawn (19.6 ms), orphans PASS; idle-rss FAIL in the full run (32.7 MB)
but 3/3 PASS alone (17.2 MB, test-timing artifact); overhead 0.220 ms vs 0.2 ms FAIL (marginal).

## Local, same machine: node (J) vs Rust wasm (W) vs Rust native (N)

One backend serving all three runtimes, 100 cases, warm 50 iterations at concurrency 1, cold 2 rounds. Ratios are
numerator/denominator times, so above 1 means the denominator is faster.

| metric (client time) | J/W | J/N | W/N | N slower than W (5% band) |
|---|---|---|---|---|
| warm p50 | 1.859 | 2.427 | 1.391 | 12 |
| cold p50 (2 rounds) | 2.299 | 2.896 | 1.350 | 21 |
| warm server exec p50 | 2.110 | 2.730 | 1.428 | 12 |
| cold server exec p50 | 2.539 | 3.126 | 1.396 | 19 |

Phase-1 correctness (three-way): 100/100 equal. Native does not beat wasm on cheap call-dominated cases (`cb`, `net`);
cold `cb` p50 is 5.94 ms native vs 3.68 ms wasm. Local numbers have no network and are not comparable with cloud
numbers; native is self-hosted only.

## Caveats

- Cloud deployment was disabled mid-run (free-plan limits): warm and concurrency are "not measured" for data-014, data-015,
  crypto, media, mem (all runtimes); cold is complete. Not shown as numbers or as failures.
- Cold is the median of only 2 rounds. Cloud warm is 15 iterations. net not run on cloud. 37 cases n/a on ts-v8, 4 on cloud node.
- Cloud client time includes ~110 ms network, compressing ratios; see the server exec view.
- Local node data-008/mem-001/002/004 come from the nodena rerun.
- Native loses to node on cheap cases at concurrency 50 (23 cases slower), see the report.
